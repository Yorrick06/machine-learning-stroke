# Machine Learning Stroke

Portfolio-opdracht voor het voorspellen van herseninfarcten met verschillende classificatiemodellen.

- `data/`: train-, test- en voorbeeldsubmissiondata
- `notebooks/index.ipynb`: EDA, modellering, evaluatie en conclusie
- `pva.md`: planning, taakverdeling en eisen

Open `notebooks/index.ipynb` in Jupyter en voer de cellen van boven naar beneden uit.
